# Gestion des Boîtes à Livres - Application Web

**Description**  
Ce projet est une **application web full-stack** développée dans le cadre de ma formation à la Wild Code School.  
Elle permet de **gérer les emprunts et les dons de livres** dans les boîtes à livres situées dans la rue, avec un **scan d’ISBN pour les emprunts et retours**.  

L’application offre une interface intuitive et moderne pour suivre la circulation des livres et faciliter la participation des utilisateurs aux boîtes à livres de manière simple et collaborative.

---

## Fonctionnalités

- Gestion des **boîtes à livres** et des livres disponibles  
- **Enregistrement des emprunts et des retours** via scan d’ISBN  
- Suivi des **dons** et de l’inventaire des livres  
- Interface utilisateur responsive et dynamique avec **React**  
- API backend avec **Express** pour gérer les opérations et les transactions  

---

## Stack Technique

- **Frontend** : React  
- **Backend** : Node.js + Express  
- **Base de données** : mysql
